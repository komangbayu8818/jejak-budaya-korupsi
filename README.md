# 🔥 Jejak Budaya di Era Digital

Website statis bertema kritik terhadap **warisan korupsi di Indonesia**: dari upeti zaman kerajaan, VOC, tanam paksa, Orde Lama, Orde Baru, Reformasi, sampai era digital.

**Lihat websitenya:** https://komangbayu8818.github.io/jejak-budaya-korupsi/

## Fitur
- Linimasa korupsi dari masa ke masa dengan fakta "RAHASIA" yang bisa dibuka
- Penghitung angka & grafik Indeks Persepsi Korupsi 2014–2024
- Galeri satir (ilustrasi SVG beranimasi + poster)
- Kartu "Dulu & Kini", kalkulator kerugian negara, dan kuis "Korupsi atau bukan?"
- Efek api kebakaran, bara beterbangan, dan musik latar

## Teknologi
HTML, [Tailwind CSS](https://tailwindcss.com) (CDN), CSS, dan JavaScript murni — tanpa instalasi.
Cukup buka `index.html` di browser.
